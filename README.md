#StudyMitra — Study Planning Solution

StudyMitra is a web-based study planning project designed to help students organize their preparation based on their available time and study goals.

## Live Demo
https://studymitra-planner.netlify.app

## Features
- Student-focused study planning concept
- Simple and accessible web interface
- Designed to support study organization and preparation

## Technologies Used
- HTML
- CSS
- JavaScript
